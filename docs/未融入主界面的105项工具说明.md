- **定向征品**：查询主题和经营类目 → 检查商品适配 → 准备征品图片 → 生成主题草稿 → 检查后再进入发布流程。
- **3D制作**：检查资格 → 从视频生成 → 查询状态 → 查看模型 → 核对商品资料 → 关联商品。
- **店铺装修**：查询资料和模板 → 创建页面 → 生成预览 → 修改 → 查询完成状态 → 确认对应版本的发布。
- **客户沟通**：查询联系人及会话 → 按时间读取消息 → 解析卡片或翻译 → 人工核对回复内容。发送消息合同补齐前，不将其视为已完成的可用链路。

这些组合是业务设计建议，不表示当前插件已把全部步骤自动串联完成。
