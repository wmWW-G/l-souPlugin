# 来搜工作台：安装与首次测试

适用：Windows 10/11（Intel/AMD 64 位）、Intel Mac、M 系列 Mac。1.0.2 的来搜窗口和随包 Node 构建目标为 macOS 11.0，但依赖的 WorkCTL 0.1.55 已在 macOS 11.5.2 报告系统符号缺失；当前整套插件不能宣称兼容 macOS 11，Mac 请使用 macOS 12.0 或以上并实机验证。仅提供三个独立安装包：Mac（M芯片）、Intel Mac、Windows（x64），请按电脑选择对应ZIP。

## 只需三步

1. 打开并登录 Accio Work，在「插件 → 添加插件 → 导入插件」中选择整个 ZIP，无需手工解压。
2. 安装启用后，在 Accio 对话中说「打开来搜插件」，显示来搜启动页。
3. 点击橙色「启动工作台」，打开桌面窗口；查看「经营总览」和「商品运营」的真实数据。

不要安装 Node/Rust，不需要命令行，也不用访问浏览器网址。需提前在当前空间安装「国际站生意助手」并授权自己的店铺。AI 运营待办需要自己的 Dify 配置；缺少它不代表店铺数据连接失败。

## 交给 Accio Work 的安装 Prompt

请安装并启用我提供的「来搜工作台」插件 ZIP。通过插件管理界面导入，不要重新编译源码或要求我敲命令。安装后在对话里展示来搜 HTML 启动页，等我点击「启动工作台」再打开 Tauri 桌面窗口和经营总览，使用我当前活动空间的国际站生意助手授权读取真实数据，再检查商品运营页。不要发布商品或修改广告。若无法使用，请读取本机来搜工作台日志，判断是插件启动、缺少店铺授权还是平台环境问题，用一句话告诉我应该点哪里；不要让我排查技术细节，不要输出账号令牌或 API Key。

## 遇到问题

1.0.3 内置「来搜启动排障」Skill。直接在 Accio Work 中说：**“用来搜启动排障 Skill 检查并恢复工作台。”** 它会检查当前会话、实际安装的工具、系统与包内程序，自动重新定位更新后的工具，并尝试恢复来搜自身的执行权限或失败窗口。登录、插件安装或系统兼容问题会给出对应原因和需要点击的入口。

恢复完成后仍需确认 Tauri 窗口已打开，并能在经营总览、商品运营看到当前店铺数据。排障不会发布商品、修改广告、复制账号凭据或关闭系统保护。如果系统提示未知发布者或拦截，把实际提示反馈给提供插件的人。

供 Accio 排查：macOS 日志在 ~/Library/Application Support/com.lsou.workbench/；Windows 日志在 %LOCALAPPDATA%/com.lsou.workbench/。只回传不含敏感信息的错误摘要。Windows 依赖 Microsoft WebView2；若缺少，使用 Microsoft 官方安装入口解决，不要求用户安装开发工具。

MCP 提供 `lsou_desktop_launchpad`、`lsou_desktop_status`、`lsou_desktop_open`、`lsou_desktop_diagnose`、`lsou_desktop_repair`、`lsou_desktop_stop`。桌面/MCP 不可用时，Accio 可执行 `lsou-workbench --diagnose` 获取相同的脱敏检查；完整步骤见包内 `skills/lsou-startup-recovery/SKILL.md`。诊断不输出原始日志或账号文件。最后一次启动摘要保存在本机 `startup-status.json`，须结合时间和进程状态判断，不能当作当前成功证据。

## 1.0.4 启动页

新版插件连接后先待命。启动页由内置 `lsou-launchpad` Skill 在 Accio 对话内渲染，按钮向当前对话发送启动、状态或排障请求，随后调用对应工具。卡片不会用动画假报成功；后端结果与桌面数据分别核验。独立打开 HTML 仅供设计预览。安装详情页自动弹出 HTML 尚无已确认的入口，不能与对话里的启动页混为一谈。

## 1.0.5 Windows 诊断复测

本轮Windows包修正慢启动时的工具响应：20秒内仍未完成则返回“仍在启动/恢复”，由Accio稍后读取状态；这不代表启动成功，也不需要重复开窗口。新增本机 `native.log` 和诊断里的 `nativeStartup.events`，用于确认卡在原生程序、Node创建、Windows进程管理还是后端退出。日志只保存阶段和数值错误码。`lastStartup.source=standalone` 表示一次独立后端运行，不能证明工作台窗口成功。若仍卡住，让Accio读取诊断并反馈原生阶段摘要。此包仍需Windows实际导入、点击启动和店铺数据验收。

## 1.0.8 启停增强版（lifecycle-r1）

可以直接说“启动来搜工作台，跳过 HTML 动画”；关闭时说“停止来搜工作台”。停止只处理当前 MCP 启动的窗口并触发所属后端清理，插件保持待命，再说启动即可。重复停止会合并，停止请求会取消在途恢复；无需卸载插件。状态中的 buildRevision 为 lifecycle-r1。

本次增强仅更新启动脚本与 Skill，沿用 1.0.8 原生程序和业务资源；不包含自动更新功能。后端 ready、窗口可见、真实数据加载是三个独立验收层次，工具未观察窗口或数据时不会标成已验证。Windows 仍需实测启停与重新启动。

## 1.0.9 图片上传

产品发布页的新图片通过 Accio Work 自带 CDN 上传，无需配置存储桶。图片上传成功后自动带入发品资料；发布仍使用原有确认及串行队列。图片接口已在 Accio Work 0.32.2 核验；登录失效、版本不支持或上传失败会在图片旁提示并保留重试入口。
